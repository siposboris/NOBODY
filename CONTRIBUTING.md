# Contributing

Nobody welcomes contributions. Please open an issue or pull request describing proposed behavior, with tests and documentation.

- Exactly one human syntax language per .nbd file.
- All syntax and built-in names are lowercase ASCII; strings/comments may have Unicode.
- Source translation is Nobody → Nobody; do not silently generate Python.
- Mark options **implemented**, **experimental** or **planned**. Unsupported modes must fail explicitly.
- Update CHANGELOG.md, docs/FEATURES.md and docs/ROADMAP.md with meaningful changes.
- Include reproducible test results and known limitations.
- Respect MIT licensing and disclose significant AI assistance where relevant.
